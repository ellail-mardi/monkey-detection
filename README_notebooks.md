# Notebooks

Two Google Colab / Jupyter notebooks reproduce the experiments on visual–thermal monkey detection across times of day.

| Notebook | Purpose | Approx. time (T4 GPU) |
|---|---|---|
| `01_session_grouped_cv_training.ipynb` | Splits the test sessions into 3 balanced folds, retrains a visual and a thermal YOLO11n detector per fold, and writes out-of-fold predictions to `cv/oof_preds.pkl`. | 30–60 min (6 trainings; resumable) |
| `02_evaluation.ipynb` | Evaluates single-modality detectors, fixed-weight fusion and Adaptive Late Fusion (ALF): overall performance with session-level bootstrap intervals, results by time window, ablation, quality-estimator statistics, weight sweeps and oracle headroom, per-window versus pooled evaluation, source-only versus cross-validated detectors, sensitivity analysis, latency and qualitative figure. Writes tables (CSV and Excel), figures and a configuration file to `results/`. | 10–20 min |

## Running
1. Open a notebook in Colab (Runtime → Change runtime type → GPU). Each notebook clones this repository automatically.
2. Run `01_...` first, or place a precomputed `cv/oof_preds.pkl` in the repository and run `02_...` directly.
3. Optional: set `USE_GOOGLE_DRIVE = True` in the configuration cell to keep generated files across Colab sessions.

Local use: `pip install -r requirements.txt`, set the environment variable `ALF_REPO` to the repository folder, and run the notebooks with Jupyter.

## Expected repository layout
Folder names are detected automatically (case-insensitive; Malay aliases `subuh`, `tengahari`, `senja`, `malam` are accepted for `dawn`, `midday`, `dusk`, `night`):

```
<data root>/
  test/{dawn,midday,dusk,night}/{visual,thermal,labels}/
  <training folder>val/{visual,thermal,labels}/  
weights/visual_best.pt, thermal_best.pt           # source-only detectors (optional; used for the source-only comparison and the training recipe)
cv/oof_preds.pkl                                  # generated by notebook 01 (or shipped)
results/                                          # generated by notebook 02
```
Frame pairs are matched by `session_frame` keys, e.g. `v19_00001.png` and `t19_00001.png`. If automatic detection fails, set `DATA_ROOT`, `TRAIN_DIR` or `TEST_DIR` explicitly in the configuration cell.

## Annotations
* Test pairs share one set of boxes for both frames (frames were cropped to a common field of view).
* Training pairs are annotated per modality (the two cameras are not co-located). A thermal label file `t<id>.txt` is used for the thermal frame if present.
* All boxes are merged into a single "monkey" class; duplicate boxes (IoU ≥ 0.95) are removed.
